# Incubyte-Gmail-Manual-Assessment

## Objective

This repository contains manual test cases for testing Gmail's Compose Email functionality.

### Scope

The assessment verifies:

- Compose Email window
- Recipient validation
- Subject field
- Email body
- Send functionality
- Draft functionality
- Attachments
- CC/BCC
- Keyboard shortcuts
- Browser compatibility
- Accessibility
- Error handling
- Network interruption scenarios

## Deliverables

- Traditional Test Cases
- BDD (Behavior Driven Development) Test Cases
- Positive Test Cases
- Negative Test Cases
